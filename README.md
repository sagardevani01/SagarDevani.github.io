# Sagar Devani — Personal Engineering Portfolio

A modern, high-performance, accessible personal portfolio website for **Sagar Devani**, Full Stack .NET & Generative AI Developer (Angular, Azure & AI-Assisted Engineering).

## 🚀 Live Tech Stack
- **Framework:** React 18 + TypeScript + Vite
- **Styling:** Tailwind CSS (with custom dark/light theme persistence and subtle glassmorphic styling)
- **Icons:** Lucide React & Custom SVG brand icons
- **Data Architecture:** Fully decoupled, typed single source of truth (`src/data/resumeData.ts`) strictly mapped to verified resume facts.
- **Assets:** Genuine resume PDF (`public/Sagar_Devani_Resume.pdf`) and banner asset.

## 🛠️ Quick Commands

```bash
# Install dependencies
npm install

# Start local development server (with hot reload)
npm run dev

# Run TypeScript type check and production build
npm run build

# Preview production build locally
npm run preview
```
